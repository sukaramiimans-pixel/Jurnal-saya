# Jurnal Hidupku

Aplikasi pribadi untuk membantu mengelola kehidupan sehari-hari.

## Fitur

- Jurnal harian
- Diary pribadi
- Mood tracker
- Habit tracker
- Produktivitas
- Catatan pemasukan
- Catatan pengeluaran
- Saldo keuangan
- AI Coach
- Penyimpanan lokal menggunakan LocalStorage
- PWA ready

## Teknologi

- HTML
- CSS
- JavaScript
- LocalStorage
- PWA

## Cara menjalankan

Buka `index.html` menggunakan browser.

Untuk deployment, repository dapat di-host menggunakan GitHub Pages.

## Pengembangan berikutnya

- Login pengguna
- Database cloud
- AI API sungguhan
- Push notification
- Reminder otomatis
- Grafik keuangan
- Target tabungan
- Catatan utang
- Sinkronisasi antar perangkat
- Mode gelap
- PIN untuk Diary
